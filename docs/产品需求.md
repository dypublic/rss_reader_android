# Android 个人 RSS 阅读器：首版需求

版本：v1.0 · 日期：2026-09-15

## 1. 目标与范围

为个人提供按时间从旧到新消费 RSS 文章的 Android 阅读工具。核心流程是添加订阅、逐个订阅源浏览未读、阅读正文、自动消除未读积压。

本文件整理对话中已确认的需求。第 8 节为开发时采用的边界处理，不增加新的产品功能。

首版不包含账号、服务器同步、收藏、订阅分组、跨来源的全部文章列表、手动恢复未读、深色主题、后台定时刷新、来源搜索、OPML 导入、网页全文抓取、AI 功能。OPML 导出也不纳入首版。

## 2. 平台与视觉

- Android 原生应用，Kotlin + Jetpack Compose，本地保存数据。

- 使用浅灰背景、白色内容区、深色文字和橙色强调，仅浅色主题，不跟随系统切换。
- 截图中的新闻、品牌名称是示例内容，实际由订阅源提供；系统状态栏不是应用内仿制元素。
- 默认进入订阅页。取消参考图的底部导航、内容类型切换和收藏入口。设置从订阅页右上角进入。

## 3. 页面需求

### 3.1 订阅页

- 平铺订阅源，按添加顺序固定排列，显示图标、名称和各自未读数量；零未读来源仍显示，未读数为 0。不支持分组，也不显示跨来源的全部文章入口。
- 点击来源进入该订阅源的文章列表。
- 添加订阅只支持输入或粘贴 RSS 地址：输入 → 验证 → 显示名称 → 确认添加。
- 已存在的地址提示已订阅，不重复创建。
- 添加失败保留输入，并区分地址无效、请求失败、内容无法解析等原因。
- 长按订阅源打开操作菜单，支持重命名和删除。删除前确认，并清除该来源的本地文章，包括未读文章。

### 3.2 文章列表

- 默认显示未读，可切换全部。
- 同一订阅源内的未读和全部列表都按发布时间最旧优先排列；“全部”仅指当前订阅源。
- 文章没有有效发布时间时，用首次获取时间参与排序；同一时间的文章使用稳定次序，刷新后不能随机重排。
- 每条显示来源、时间、最多两行标题、最多两行摘要；有图时在右侧显示缩略图，无图时文字使用可用宽度。
- 未读显示红点；已读移除红点、文字变灰，仍须保持文字可读。
- 点击整条进入阅读页。
- 每次从订阅页进入列表，从最旧未读开始；从阅读页返回时恢复列表位置。
- 下拉刷新；支持将当前订阅源全部标为已读。批量已读前确认框显示来源名称与篇数；只处理操作开始时该来源已有的文章，新刷出的文章保持未读。

### 3.3 阅读页

- 展示标题、来源、发布时间和 RSS 提供的正文。
- 保留段落、图片、链接、引用、列表和代码块的基本结构。
- 来源仅提供摘要时展示摘要，通过打开原文进入系统浏览器，不抓取额外全文。
- 支持字号调整并保存、阅读位置恢复、点击图片放大及缩放。
- 无收藏入口，仅浅色主题。

### 3.4 设置

- 提供全局阅读字号调整；不提供主题切换。
- 首版不增加未讨论的账号、同步、推荐或通知设置。

## 4. 已读行为

### 4.1 触发方式

1. 打开文章立即标为已读。
2. 用户向下浏览列表，文章完整越过列表可见区域顶部时标为已读。
3. 快速滑动同样生效，不要求停留时长；跨越范围中的条目即使未被完整渲染，也须标为已读。
4. 手动将当前订阅源的文章全部标为已读。

只有部分内容越过顶部、文章仍在屏幕内时，不因滚动标记。向回翻阅、首次加载、刷新、筛选切换和位置恢复造成的位置变化，均不触发滚动已读。

### 4.2 列表稳定性

- 变为已读后立即更新该来源未读数，文章原位变灰。
- 当前未读列表中暂时保留刚读过的条目，防止阅读过程中位置跳动。
- 重新进入列表或手动刷新后，按真实未读状态重新筛选。
- 从阅读页返回保留原列表位置，不能作为一次重新进入而移除条目。
- 当前来源的“全部”列表保留已读文章，直至满足清理条件。
- 当前来源的“全部”列表也执行向下划过即已读；已读文章再次划过不改变状态。

### 4.3 状态与保留时间

- 未读 → 已读：记录本次标为已读的时间。
- 已读 → 已读：再次打开或重复标记不延长保留时间。

## 5. 获取与刷新

- 每次重新启动 App 都刷新；从后台返回时，距上次刷新超过 15 分钟才自动刷新。支持随时手动下拉刷新；不运行后台定时刷新任务。
- 首次添加来源，仅 RSS 当次提供文章中最新 20 篇标为未读，不足 20 篇时全部未读。其余标为已读，从导入时间开始计算保留期。
- 支持 RSS 2.0 和 Atom 订阅地址；不接受普通网页作为订阅源。
- 首次选出的 20 篇，在列表内仍按从旧到新排列。
- 首次导入之外，后续发现的新文章全部标为未读。
- 刷新不能创建重复文章，不能重置已有文章的已读状态。
- 单个来源失败不妨碍其他来源；失败时保留已有数据并提供重试入口。
- 刷新期间保持当前内容可读，不以空白页面覆盖已有文章。

## 6. 数据生命周期

- 已读文章从标为已读时起保留 30 天，满期后在启动时清理。
- 未读文章一直保留，不因发布时间早或来源不再返回而删除。
- 清理正文后保留轻量去重记录，防止下次刷新重新导入成未读。
- 已下载文字可离线阅读。首版不承诺图片完整离线可用。
- 关闭或重启 App 后，订阅、文章、阅读状态、字号、阅读位置仍须保留。
- 主动删除来源属于上述保留规则的例外：确认后删除对应未读和已读文章。

## 7. 必须覆盖的页面状态

| 状态 | 行为 |
|---|---|
| 尚无订阅 | 提示添加 RSS 地址，提供添加入口 |
| 来源没有文章 | 显示暂无文章，支持刷新 |
| 所有文章已读 | 显示已读完，提供切换全部入口 |
| 正在刷新 | 保留内容并显示刷新进度状态 |
| 来源刷新失败 | 显示错误和重试入口，已有文章可读 |
| 正文或图片不可用 | 保留可显示内容，提供原文入口；不无限加载 |
| 离线 | 已缓存文字可读，网络操作失败有明确反馈 |

## 8. 开发边界处理

以下规则解决网络、数据和布局边界。实现时按这些规则处理，并用验收用例验证；如果发现影响使用方式，再回到产品需求确认。

- 刷新请求合并：手动下拉随时可发起；正在执行的同类请求不重复并发。
- 文章识别：按来源内 GUID/Atom ID 优先，其次链接，再以稳定内容指纹兜底。不同来源的文章不做跨来源合并。
- 刷新插入：以文章标识和滚动锚点保持屏幕内容稳定，不能把自动插入造成的位移算作用户划过。
- 默认未读无文章时显示读完状态，不静默切换全部。
- 标题或摘要为空：缺失摘要时不显示空行；无标题时显示“无标题”，保留来源及原文入口。
- 正文处理：不执行来源中的脚本，不允许正文直接访问本地私有文件；正文链接通过外部浏览器打开。
- 图片缓存：按需加载；大小上限在实现时确定，不作永久图片归档。

配套验收清单见《RSS阅读器验收用例.md》。核心逻辑用固定数据自动验证，页面和 Android 行为用本地 Android 16 ARM64 模拟器验证，真实来源用于联网联调。

交付物：可安装 APK、源码、测试结果及已知问题。当前已实现并在模拟器验证 v0.1 调试版，实际结果见《RSS阅读器开发验证.md》；真实手机适配不因模拟器通过而视为已验证。
